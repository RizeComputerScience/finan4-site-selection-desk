# The Site Selection Desk

Corporate Finance (Rize-powered course), Unit 5. An NPV practice game: eight seeded cards, judged with per-mistake feedback, ending in a PNG receipt that instructors verify with `verify.html`.

- `index.html`: the game. `verify.html`: the instructor receipt checker. `desk-core.js`: shared generation, judging and receipt code.
