# The Site Selection Desk

Corporate Finance (Rize-powered course), Unit 5. An NPV practice game (version 2, 2026-11-02): a worked example, a quick check, five seeded sites judged row by row with help that shows the setup, a short written note, and a completion-graded PNG receipt that instructors can spot-check with `verify.html`. Design rules: `projects/coursedev/process/standards/interactive-assignments.md`.

- `index.html`: the game. `verify.html`: the instructor receipt checker. `desk-core.js`: shared generation, judging and receipt code.
